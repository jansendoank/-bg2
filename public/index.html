Panduan Deployment Panel Wipsbyte & Hosting

Langkah-langkah lengkap untuk menjalankan Web Dashboard dan WhatsApp Bot di panel hosting Wipsbyte, Pterodactyl, cPanel, atau VPS.

1 Konfigurasi Startup Command di Panel Wipsbyte

Di panel Wipsbyte (menu Startup atau Settings), pastikan perintah startup utama adalah:

npm start

Script npm start akan secara otomatis menjalankan node server.js yang menghidupkan server web dashboard sekaligus bot engine.

2 Port dan Variabel Lingkungan (Environment Variables)

Panel Wipsbyte secara otomatis menetapkan variabel PORT. Web Dashboard Onepiece sudah membaca process.env.PORT secara dinamis sehingga tidak akan terjadi bentrok port.

PORT=3000 # Atau port yang dialokasikan panel Wipsbyte
ADMIN_PASSWORD=onepiece2026 # Password login dashboard admin
AUTO_CONNECT_WHATSAPP=false # Set 'true' jika ingin otomatis konek saat restart

3 Penyimpanan Sesi Persisten (Session Storage)

Kredensial login WhatsApp tersimpan secara aman di folder ./session/. Ketika server di-restart atau panel reboot, bot akan otomatis menyambung kembali tanpa perlu scan QR ulang.

4 Akses Dashboard dari Browser

Setelah server aktif, buka URL IP/Domain dan Port yang dialokasikan Wipsbyte (misal: http://ip-server:port). Masukkan password admin untuk mulai mengontrol bot dan mengeksekusi semua command.
